menu_book System Guide

videocam 1. Live Detection Dashboard

The main dashboard monitors your crop environment using camera feeds.

  • Cameras: Toggles the live video feeds on and off.
  • Start Detect: Activates the AI to draw bounding boxes around detected bugs.
  • Unknown Pests: If an unregistered pest is detected, the system captures it, sends it to an external AI for analysis, and logs the new data.
  • Reload Model: Click this after "Active Learning" completes to update the system with new pest intelligence.

router 2. Hardware Control

From the dashboard, you can control the connected Arduino hardware.

  • UV Index: Displays real-time UV sensor data.
  • Relay Status: Shows if the physical relay is ON or OFF.
  • Force ON/OFF: Manually override the relay state.
  • Auto Mode: Returns control to the system's automated sensor logic.

cloud_upload 3. Image Upload

Upload a clear photo of an insect. The AI will instantly analyze the image, identify the species, and generate a comprehensive treatment plan including cultural, biological, and chemical methods.

library_books 4. Library & History

  • Pest Library: A searchable database of known pests and their specific treatments.
  • Detection History: A visual log of every pest detected by the live cameras or uploaded manually, complete with timestamps.

admin_panel_settings 5. Admin Features

Users logged in as Administrators have access to data management tools.

  • Add New Pest: Manually create a database entry for a new pest.
  • Pest List: A spreadsheet view allowing admins to edit pest details inline or upload new reference images.
